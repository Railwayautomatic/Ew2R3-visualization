Privacy

Ew2R3.org is a static website. The first release does not provide accounts, comments, or a contact form.

Analytics

Google Analytics 4 is loaded only after you select “Allow” in the consent notice. If you decline, no GA4 script is loaded. Cloudflare may still process technical request data at the network edge for security, DDoS protection, and aggregate traffic operation. The site does not create advertising profiles.

Contact

Email sent to info@Ew2R3.org is handled by the project’s email provider, not stored by this static website.
